# Website business card

## Scripts

Before running the script, make sure that the required parameter is set in the `./src/App.js` file:\
To run the project on `//localhost`  -  `const basename = "/website-business-card/"`;\
To run the project on `//GitHub`  -  `const basename = ""`.

### `npm start`

Runs the app in the development mode.

### `npm run deploy`

Creates/replaces files in the `build` folder.
Will push changes to `GitHub` in the `gh-pages` branch.
